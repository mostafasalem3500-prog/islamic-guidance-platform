# بلّغ | Baligh

منصة إرشاد إسلامي متعددة اللغات للباحثين عن الإسلام، والمسلمين الجدد، والدعاة.

## المبادئ

- عرض النصوص المنسوبة إلى المصادر الرسمية دون تغيير.
- إظهار المصدر والرابط الأصلي وبيانات الإصدار وتاريخ المزامنة.
- فصل المحتوى الرسمي عن الملخصات أو الإجابات المولدة.
- دعم اتجاهي الكتابة RTL وLTR.

## المصادر المستهدفة

- IslamHouse API v3: الكتب والمقالات والفتاوى والصوتيات والفيديو.
- QuranEnc API: ترجمات معاني القرآن وبيانات السور والآيات.
- HadeethEnc API: الأحاديث والترجمات والشروح.

## التشغيل

```bash
npm install
npm run dev
```

## الربط المنفذ حاليًا

### القرآن الكريم

تستخدم صفحة `/quran` واجهة QuranEnc الرسمية لعرض سورة الفاتحة بترجمة `english_saheeh`:

```
GET https://quranenc.com/api/v1/translation/sura/{translation_key}/{sura_number}
```

يتم الاستدعاء من الخادم عبر `src/lib/quran-enc.ts` مع تخزين مؤقت لمدة 24 ساعة.  
تمنع طبقة البيانات مفاتيح الترجمة أو أرقام السور غير الصالحة، وتعيد واجهة آمنة إذا تعذر المصدر.

### واجهات Baligh الداخلية

- `GET /api/sources` — قائمة المصادر المعتمدة وإرشادات النسبة.
- `GET /api/quran/surah?translation=english_saheeh&surah=1` — سورة مترجمة مع بطاقة مصدر موحّدة.


### مكتبة IslamHouse ومركز الداعية

- `/library` تجلب فهرس الأنواع وأول مجموعة كتب مباشرة من IslamHouse API v3.
- يستخدم المشروع المفتاح العام الموثق من المصدر، ويمكن استبداله اختياريًا بـ `ISLAMHOUSE_API_KEY` في بيئة النشر.
- `/dawah` ينشئ رابط مشاركة لصفحات المنصة مع إظهار مصدر الوجهة.
